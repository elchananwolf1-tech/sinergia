חיבור אתר וורדפרס

איך להשיג סיסמת אפליקציה?

  1. היכנסו לממשק הניהול של וורדפרס (wp-admin)
  2. לכו לתפריט: משתמשים → פרופיל
  3. גללו למטה עד לקטע "סיסמאות אפליקציה" (Application Passwords)
  4. הזינו שם למכשיר/יישום, לדוג' "EWolf Editor"
  5. לחצו על "הוסף סיסמת אפליקציה חדשה"
  6. העתיקו את הסיסמה המוצגת - היא תופיע פעם אחת בלבד!

הערה: יש לוודא שהאתר מאפשר גישת REST API ושאין חסימת CORS.
